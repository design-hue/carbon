# Carbon Mineralisation — 44.01 · COP31

Interactive kiosk experience explaining how captured CO₂ is turned into solid minerals underground — a technology developed in Oman by 44.01.

Five interactive stages with a 3D viewport (Three.js, bundled inline), narration, and an attract screen. Designed for a 1080 × 1920 portrait kiosk display and scales to fit any screen.

## Run

Open `index.html` in a modern browser. It is fully self-contained apart from the Manrope font loaded from Google Fonts.

To serve locally:

```sh
python3 -m http.server 8000
```

then visit http://localhost:8000.

## GitHub Pages

Enable Pages on the `main` branch (root) to host it at `https://design-hue.github.io/carbon/`.
